# 📊 CYBER TETRIS (사이버 테트리스)

> **Vercel 배포 완료!** 모바일 및 데스크톱 브라우저에서 완벽하게 동작하는 반응형 웹 테트리스 게임입니다.
> 
> 기본 네온 글로우 다크 테마뿐만 아니라 **실제 Microsoft Excel 화면으로 100% 위장되는 📊 엑셀 스킨**, **Boss Key(단축키 B)** 위장 기능, 그리고 **🏆 Vercel 서버리스 글로벌 명예의 전당**이 통합되어 있습니다.

---

## ✨ 주요 특징 및 핵심 기능 (Key Features)

### 1. 📊 100% 엑셀 위장 스킨 (Excel Camouflage Theme)
- **엑셀 그린 리본 바 & 수식 입력줄 (`fx`)**: 상단 헤더가 `Microsoft Excel - 2026_실적분석.xlsx` 제목과 수식창으로 전환됩니다.
- **열(A~J) / 행(1~20) 스프레드시트 그리드**: 메인 테트리스 캔버스가 실제 엑셀 시트 셀 그리드로 감싸집니다.
- **엑셀 셀 렌더링**: 테트리스 블록이 엑셀 셀 강조 색상 및 흰색 테두리로 표시되어 멀리서 보면 엑셀 작업 중인 것으로 완벽 위장됩니다.
- **하단 엑셀 시트 탭 (Sheet Tabs)**: 화면 최하단에 `Sheet1 (2026_실적분석)` 탭이 노출됩니다.

### 2. 🏆 Vercel 서버리스 글로벌 명예의 전당 & 전설의 1위 폰트 연출
- **Vercel Serverless API (`/api/highscore`)**: 전 세계 유저들의 최고점수와 닉네임이 서버리스 백엔드에 실시간 수집 및 기록됩니다.
- **닉네임 등록 시스템**: 최고 기록 갱신 여부와 관계없이 게임 종료 후 누구나 닉네임을 입력하고 명예의 전당에 점수를 남길 수 있습니다.
- **`[🏆 순위보기]` 상단 버튼**: 전 세계 Top 10 순위표를 모달로 열람 가능합니다.
- **👑 전설의 1위 화려한 폰트 연출**: 1위 챔피언 유저의 닉네임과 점수는 황금빛 그라데이션 애니메이션, 글로우 텍스트, 바운싱 왕관(`👑`) 아이콘으로 화려하게 우뚝 비춰집니다.

### 3. 📈 1만점 단위 난이도 (속도) 가속 엔진
- **10,000점 단위 자동 레벨 업**: 점수가 1만 점 누적될 때마다 레벨이 1 단계 상승합니다.
- **곡선 속도 가속 알고리즘**: 레벨이 오를 때마다 블록 낙하 지연 시간이 정교한 곡선 공식(`Math.pow(0.88, level - 1)`)으로 아주 매끄럽고 서서히 빨라져 쫄깃한 긴장감을 제공합니다.

### 4. 🎚️ 블록 전용 전폭 투명도 조절 & 4x4 정비율 미니 뷰
- **전폭 투명도 슬라이더**: 헤더 아랫줄 전폭 슬라이더를 통해 손가락 터치로 0% ~ 100%까지 1% 단위 미세 조절이 가능합니다.
- **HOLD & NEXT 연동**: 메인 판뿐만 아니라 좌측 보관(HOLD) 및 우측 대기(NEXT 3개) 미니 블록의 색상 투명도도 실시간 함께 동기화됩니다.
- **4x4 정비율 정밀 미니 그리드**: 블록이 찌그러지거나 일그러지지 않도록 1:1 비율 센터링 뷰포트를 적용했습니다.
- **🩵 눈이 편안한 하늘색 I-블록**: 일자형 블록 색상을 눈 피로도가 적은 소프트 하늘색(`#38bdf8`)으로 채택했습니다.

### 5. 🖥️ 창 이탈 자동 일시정지 & 🛑 게임종료
- **포커스 아웃 자동 일시정지**: 다른 탭으로 이동하거나 창을 최소화하면 게임이 자동으로 안전 일시정지(`PAUSED`) 처리되고 팝업 안내 모달이 노출됩니다.
- **`ESC` / `P` 일시정지 핫키**: 키보드 `ESC` 키로 자유롭게 일시정지 및 재개가 가능합니다.
- **🛑 하단 소형 게임종료 버튼**: 붉은색 게임종료 버튼을 누르면 즉시 게임이 종료되며 닉네임 입력 모달로 이동합니다.

### 6. 🕵️ 몰컴 보스키 (Boss Key: 단축키 `B`)
- 게임 도중 키보드 **`B`** 키나 **`몰컴(B)`** 버튼을 누르면 0.1초 만에 사운드가 소거되고 **`2026_하반기_사업계획서_및_실적분석_보고서.docx`** 위장 문서 화면으로 전환됩니다.

| 구분 | 사용 기술 |

## 🎮 키보드 및 터치 조작법 (Controls)

| 키 (Key) | 기능 (Action) |
| --- | --- |
| `←` / `→` | 블록 좌/우 이동 |
| `↑` / `X` | 시계 방향 회전 |
| `Z` / `Ctrl` | 반시계 방향 회전 |
| `↓` | 소프트 드롭 (천천히 내리기) |
| `Spacebar` | 하드 드롭 (즉시 착지) |
| `C` / `Shift` | 홀드 (블록 보관/교체) |
| **`P` / `Esc`** | **일시정지 / 재개** |
| **`B`** | **몰컴 보스키 (보고서 위장 화면 전환)** |

## 🚀 프로젝트 실행 및 빌드 (Getting Started)

### 1. Repository 클론
```bash
git clone https://github.com/kimkongzzak/kimtetris.git
cd kimtetris
```

### 2. 의존성 패키지 설치
```bash
npm install
```

### 3. 개발 서버 실행
```bash
npm run dev
```

### 4. 프로덕션 빌드 및 타입 검사
```bash
npm run build
```
