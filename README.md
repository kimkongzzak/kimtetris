## ✨ 주요 특징 및 핵심 기능 (Key Features)

### 1. 🧪 김박사의 테트리스 메인 스킨 & 📊 100% 엑셀 위장 스킨
- **김박사의 테트리스 네온 테마**: 세련되고 선명한 사이언/퍼플/골드 그라데이션 글로우 디자인.
- **엑셀 그린 리본 바 & 수식 입력줄 (`fx`)**: 상단 헤더가 `Microsoft Excel - 2026_실적분석.xlsx` 제목과 수식창으로 전환됩니다.
- **열(A~J) / 행(1~20) 스프레드시트 그리드**: 메인 테트리스 캔버스가 실제 엑셀 시트 셀 그리드로 감싸집니다.
- **하단 엑셀 시트 탭 (Sheet Tabs)**: 화면 최하단에 `Sheet1 (2026_실적분석)` 탭이 노출됩니다.

### 2. ⚡ Supabase DB 실시간 글로벌 명예의 전당 (`tetris_scores`)
- **Supabase Cloud PostgreSQL 데이터베이스 연동**: 유저들의 점수(`score`), 닉네임(`nickname`), 등록일시(`created_at`)가 Supabase DB에 실시간 저장 및 조회됩니다.
- **날짜 + 시간 상세 기록 (`YYYY-MM-DD HH:mm`)**: 기록 등록 시 시:분 단위까지 정확히 저장되어 실시간 순위표에 표시됩니다.
- **`[🏆 순위보기]` 상단 버튼 & 실시간 새로고침**: 상단 버튼 클릭 시 Supabase DB에서 최신 Top 10 순위표를 실시간 조회하며, 모달 내 **`[새로고침]`** 기능이 포함되어 있습니다.
- **👑 전설의 1위 화려한 연출**: 1위 챔피언 유저의 닉네임과 점수는 황금빛 그라데이션 애니메이션, 글로우 텍스트, 바운싱 왕관(`👑`) 아이콘으로 우뚝 비춰집니다.

### 3. 📱 스케치 기반 모바일 3단 터치 패드 & 데스크탑 완벽 숨김
- **모바일 3단 레이아웃 (<= 768px)**:
  - **1단 (상단)**: `HOLD` (보관/교체) | `DROP` (하드드롭 ⚡)
  - **2단 (중앙)**: `↻` (시계방향 회전 원형 버튼)
  - **3단 (하단)**: `◀` (좌) | `▼` (아래) | `▶` (우)
- **데스크탑(PC) 자동 숨김**: PC 브라우저 환경에서는 하단 터치 버튼을 완전히 숨겨 깔끔한 데스크탑 화면을 제공합니다.

### 4. 🎨 UI/UX 밸런스 정돈 & 닉네임 입력폼 디자인
- **중복 일시정지 버튼 정리**: 일시정지 중일 때 메뉴 패널에는 `일시정지 중` 상태만 깔끔하게 노출되어 모달 팝업과 중복되지 않도록 정리했습니다.
- **프리미엄 닉네임 입력폼**: 유저 아이콘(`User`), 글자 수 실시간 카운터(`0/12`), 네온 글로우 포커스 외곽선, 등록 성공 에메랄드 체크 태그가 적용되었습니다.

### 5. 🕵️ 몰컴 보스키 (Boss Key: 단축키 `B`)
- 게임 도중 키보드 **`B`** 키나 **`몰컴(B)`** 버튼을 누르면 0.1초 만에 사운드가 소거되고 **`2026_하반기_사업계획서_및_실적분석_보고서.docx`** 위장 문서 화면으로 전환됩니다.

## 🗄️ Supabase DB 테이블 DDL SQL

Supabase 콘솔 **SQL Editor**에서 아래 쿼리를 실행하여 테이블을 생성할 수 있습니다.

```sql
-- 1. 테트리스 점수 기록 테이블 생성 (기록 + 닉네임 + 등록일시)
CREATE TABLE IF NOT EXISTS public.tetris_scores (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nickname VARCHAR(50) NOT NULL,
    score INTEGER NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. 최고 점수 순 빠른 조회를 위한 인덱스 생성
CREATE INDEX IF NOT EXISTS idx_tetris_scores_score 
ON public.tetris_scores (score DESC);

-- 3. Row Level Security (RLS) 및 접근 권한 설정
ALTER TABLE public.tetris_scores ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read access" 
ON public.tetris_scores FOR SELECT 
USING (true);

CREATE POLICY "Allow public insert access" 
ON public.tetris_scores FOR INSERT 
WITH CHECK (true);
```

## 🎮 키보드 및 터치 조작법 (Controls)

| 키 (Key) / 버튼 | 기능 (Action) |
| --- | --- |
| `←` / `→` / `◀` `▶` | 블록 좌/우 이동 |
| `↑` / `X` / `↻` | 시계 방향 회전 |
| `Z` / `Ctrl` | 반시계 방향 회전 |
| `↓` / `▼` | 소프트 드롭 (천천히 내리기) |
| `Spacebar` / `DROP` | 하드 드롭 (즉시 착지) |
| `C` / `Shift` / `HOLD` | 홀드 (블록 보관/교체) |
| **`P` / `Esc`** | **일시정지 / 재개** |
| **`B`** | **몰컴 보스키 (보고서 위장 화면 전환)** |
